# The basics
Tap a tube, then tap another tube to pour the top colour into it. You can pour only onto the same colour or into an empty tube.

Goal: every tube holds a single colour.

# Customer order
Each level shows a small order bar. Put the shown colours in the numbered tubes (Tube 1, Tube 2 ...). You get ticks, more coins and 3 stars. It is a bonus - you can win without it.

# Powers
- Hint shows the next good move.
- Tube adds an extra empty tube.
- Bomb removes one colour, Magnet pulls one colour into a tube.
- Rewind goes back three moves, Auto-sort plays moves for you.
- Thaw melts frozen tubes, X-Ray shows hidden layers.

# Modes
- Levels: 1000 levels in worlds with new rules.
- Daily Puzzle: a fresh puzzle every day.
- Relax: endless calm levels with no stars and no pressure.

# Safe mode
Safe mode (Settings) blocks any move that would make the level impossible, so you can never get stuck.
